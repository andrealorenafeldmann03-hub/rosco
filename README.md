# rosco
**El Gran Rosco Escolar** es un juego interactivo para segundo ciclo de primaria con estética pixel art. Los participantes juegan letra por letra con roscos y preguntas independientes, 1 minuto por turno y 3 niveles de dificultad (10, 18 o 25 letras). Fomenta el aprendizaje curricular usando apodos lúdicos.
